<h2><a href=https://www.codewars.com/kata/52608f5345d4a19bed000b31/train/javascript target="_blank">Chinese Numeral Encoder</a></h2><h3>4 kyu</h3><p>Create a function that takes a Number as its argument and returns a Chinese numeral string. You don't need to validate the input argument, it will always be a Number in the range <code>[-99999.999, 99999.999]</code>, rounded to 8 decimal places.</p><p>Simplified Chinese numerals have characters representing each number from 0 to 9 and additional numbers representing larger numbers like 10, 100, 1000, and 10000. </p><pre><code>0 líng 零1 yī 一2 èr 二3 sān 三4 sì 四5 wǔ 五6 liù 六7 qī 七8 bā 八9 jiǔ 九10 shí 十100 bǎi 百1000 qiān 千10000 wàn 万</code></pre><p>Multiple-digit numbers are constructed by first the digit value (1 to 9) and then the place multiplier (such as 10, 100, 1000), starting with the most significant digit. A special case is made for 10 - 19 where the leading digit value (yī 一) is dropped. Note that this special case is only made for the actual values 10 - 19, not any larger values.</p><pre><code>10 十11 十一18 十八21 二十一110 一百一十123 一百二十三24681 二万四千六百八十一</code></pre><p>Trailing zeros are omitted, but interior zeros are grouped together and indicated by a single 零 character without giving the place multiplier.</p><pre><code>10 十20 二十104 一百零四1004 一千零四10004 一万零四10000 一万</code></pre><p>Decimal numbers are constructed by first writing the whole number part, and then inserting a point (diǎn 点), followed by the decimal portion. The decimal portion is expressed using only the digits 0 to 9, without any positional characters and without grouping zeros.</p><pre><code>0.1 零点一123.45 一百二十三点四五</code></pre><p>Negative numbers are the same as other numbers, but add a 负 (fù) before the number.</p><p>For more information, please see <a href="http://en.wikipedia.org/wiki/Chinese_numerals" data-turbolinks="false" target="_blank">http://en.wikipedia.org/wiki/Chinese_numerals</a>.</p>
